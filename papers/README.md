#  Contents of the _papers_ directory

This directory contains the papers required for awarding the doctoral degree. Moreover, the two papers from 2025 and early 2026 resulting from the collaboration of the PhD candidate with the ICE department are also included. Please refer to the [guide](https://github.com/drakop/phd_theodork/blob/main/guidelines.md) of this [repository](https://github.com/drakop/phd_theodork) for an explanation of each paper.
